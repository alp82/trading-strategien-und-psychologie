# Trading Strategien und Psychologie

Eine Präsentation zu Trading-Strategien, Risikomanagement und der Psyche dahinter.

70-90 % der Trader verlieren langfristig Geld. Nicht weil ihnen die Indikatoren fehlen - sondern Plan, Disziplin und Nerven. Genau darum geht's hier.

## Inhalt

1. **Grundlagen** - Technische und fundamentale Analyse, Haltedauern, Strategie-Archetypen
2. **Risikomanagement** - Order-Typen, Stop-Loss, Position Sizing, Win-Rate vs. R/R
3. **Trading Psychologie** - Kognitive Verzerrungen, Emotionen, Leitsätze, Routinen
4. **Praxis** - Drei konkrete Trading-Pläne (halten, OCO, gestaffelt)

Dazwischen: ein interaktives Chart-Quiz, das zeigt, wie sehr Zeithorizont und Durchhaltevermögen über den perfekten Einstieg entscheiden.

## Setup

```bash
pnpm install
pnpm dev      # Live-Präsentation auf localhost:3030
pnpm build    # Statischer Export
pnpm export   # PDF
```
